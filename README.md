# StoryCanvas · AI 视频创作画布

无限画布 + 节点式工作流的在线 AI 视频创作工具。把文本、脚本、分镜、图片、视频、音频做成可自由拖拽连线的节点，上游产物自动成为下游输入，一句话梗概一路跑到成片。

## 在线使用

打开即可用，无需安装、无需联网注册，全部生成能力在浏览器本地完成。支持安装为桌面 / 手机应用（PWA），离线也能编辑。

## 核心流程

```
文本节点（一句话梗概）
   └→ 脚本节点 → AI 拆分镜（自动给出景别 / 运镜 / 时长）
        └→ 图片节点（批量排出关键帧）
             └→ 视频节点（图生视频）
                  ├→ 音频节点（配乐 / 配音 / 音效）
                  └→ 时间轴 → 预览成片
```

## 功能

- **画布**：无限画布、滚轮缩放、空格平移、框选、网格吸附、导航小地图、流程组框（Ctrl+G）
- **排列**：多选对齐 / 等距分布、按链路拓扑自动整理布局（Ctrl+Shift+T）、节点锁定（Ctrl+Shift+L）
- **命令面板**：Ctrl+K 模糊搜索所有操作、插入节点、跳转到任意节点
- **一键运行**：Ctrl+Enter 按拓扑顺序跑通整条链路；也支持从某节点向后运行
- **时间轴**：片段排序 + 串行预览成片
- **导出**：工程 JSON、素材打包 ZIP、SRT 字幕、分镜表 CSV、素材清单、画布截图 PNG
- **PWA**：可安装到桌面与手机主屏，Service Worker 离线缓存

## 关于生成引擎

当前使用**浏览器本地推理演示引擎**（无服务端、无 API Key）：

| 产物 | 实现方式 |
|---|---|
| 图片 | Canvas 按提示词语义程序化渲染，6 套场景 + 6 套调色板 + 颗粒暗角后期，同种子可复现 |
| 视频 | 底图叠加粒子 / 云雾 / 呼吸光动态层，`captureStream + MediaRecorder` 实时录制成 webm |
| 音频 | WebAudio 离线合成后自行编码为 wav（配乐 / 旁白 / 音效三种合成器） |
| 分镜 | 本地叙事结构生成器：从梗概产出带景别 / 运镜 / 时长的分镜表 |

若要接入真实模型，只需替换 `js/gen.js` 里的 `SF.gen.image / video / audio / shots` 四个函数，节点、画布、时间轴逻辑无需改动。

## 本地运行

纯静态站点，无构建步骤、无依赖：

```bash
# 方式一：直接双击 index.html
# 方式二：起个静态服务
python -m http.server 8080
```

> 注意：Service Worker 在 `file://` 协议下不注册，本地建议用 http 方式打开以体验离线能力。

## 快捷键

| 操作 | 快捷键 |
|---|---|
| 新建节点 | 双击画布空白处 |
| 命令面板 | Ctrl+K |
| 平移画布 | 空格拖动 / H |
| 适应画布 | F |
| 自动整理布局 | Ctrl+Shift+T |
| 锁定选中节点 | Ctrl+Shift+L |
| 打包为流程组 | Ctrl+G |
| 一键运行整条链路 | Ctrl+Enter |
| 撤销 / 重做 | Ctrl+Z / Ctrl+Shift+Z |

## 目录结构

```
index.html        页面骨架
css/style.css     深色影视工作台主题
js/util.js        工具函数（图标 / toast / 下载）
js/store.js       状态层：图结构、撤销重做、持久化
js/gen.js         本地 AI 生成引擎（图片 / 视频 / 音频 / 分镜）
js/nodes.js       节点类型注册表、渲染与执行
js/edges.js       连线 SVG 与拖拽连接
js/canvas.js      画布交互：平移缩放、框选、排列、整理
js/inspector.js   右侧属性面板
js/timeline.js    底部时间轴与预览
js/exportkit.js   ZIP 打包 / SRT 字幕 / 画布截图
js/app.js         启动编排、命令面板、快捷键
manifest.json     PWA 清单
sw.js             Service Worker
```
